# WebDev2 — Week 2

Spring Boot project generated for the WebDev2 Week 2 lab.

## Running the application

```bash
# Using the local Maven installation
mvn spring-boot:run

# Or using the Maven wrapper (after JAVA_HOME is set)
.\mvnw.cmd spring-boot:run
```

The application starts on **port 8082** (configured in `application.properties`).
